## 4. Lo aprovechable para este curso

1. **U7 Proporcionalidad (ahora)**: las cuatro partes del Tema 6 son un banco de varias decenas de problemas
   propios ya ordenados (directa → porcentajes → repaso → directa o inversa) y varios vídeos propios.
   Sirven para las hojas, para el examen y como contextos de las prácticas de la app. Antes de usarlos,
   pasarles el repaso de realismo.
2. **U6 Álgebra**: la lista de problemas de «Ecuaciones con soluciones».
3. **U2 Divisibilidad**: los apuntes de criterios con ejemplos (ampliación: 11, 4, 8, 25, compuestos)
   y los cinco juegos de Scratch, candidatos a convertirse en prácticas de la app con contador.
4. **U5 Decimales**: la lista de vídeos por apartado, lista para enlazar desde la página de unidad.
5. **Técnicas de estudio**: para la página de familias y para tutoría.
6. **Carpetas de Drive incrustadas** (Archivos, Acertijos, Temas 3, 6 y 8, Ecuaciones): falta abrirlas
   y ver qué contienen; es lo único del sitio que queda sin inventariar.
