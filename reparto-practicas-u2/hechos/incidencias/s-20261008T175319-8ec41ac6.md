## Para que no se repita
En este árbol NUNCA `--autostash`, `git stash`, `git checkout -- .`, `git reset --hard`. Si el push
se rechaza: `git pull --rebase origin main` falla con «unstaged changes» porque hay ficheros de
otros a medias; lo que vale es `git fetch origin && git rebase origin/main`… que tampoco pasa
con el árbol sucio. Salida segura: `git push` otra vez tras esperar, o un worktree limpio
(`git worktree add /tmp/x origin/main`, cherry-pick del commit propio, push desde allí).
Esto debería ir a proyecto.md («Repositorio git»): es de la coordinadora.
