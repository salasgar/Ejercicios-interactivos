como «4 personas, 300 g → 10» puestos en la receta de leche (300 mL) o «3 min, 75 páginas → 8 min» puestos en una receta (3 personas,
75 g → 8): por eso aquí van **dos huellas por caso**.

**«El mismo caso»** es la terna «a ⟶ b; c ⟶ ?» (en «al revés», `sentido === 'inversa'`, la terna «b ⟶ a; d ⟶ ?»), por valor y sea cual
sea el contexto, con dos huellas: los tres números **tal como se escriben** (sin unidad) y los tres **en la unidad base** (así «750 g →
4,50 €; 2 kg» es el mismo caso que «0,75 kg → 4,50 €; 2 kg»).

**Qué hay que añadir a `logica.js`** (y las huellas de abajo en un `reserva.js` nuevo, como `practicas/razones/reserva.js`):
```js
import { huellaCaso } from '../_comun/proporcion.js';
export function huellasDe(it) {
  const t = it.sentido === 'inversa' ? ['b', 'a', 'd'] : ['a', 'b', 'c'];
  return [huellaCaso('directa', t.map(k => Q(it, k).valor)), huellaCaso('directa', t.map(k => Q(it, k).valorBase()))];
}
```
Los cuatro generadores vuelven a sortear mientras `huellasDe(it).some(h => HUELLAS_RESERVADAS.has(h))`. Test: en 3000 ítems por ejercicio,
ninguno reservado; `grep` del test y de `reserva.js` contra el TSV del examen antes de comitear.
