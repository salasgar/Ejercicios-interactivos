## Qué hay que hacer

Dos ejercicios:

1. **¿Verdadero o falso?** Una igualdad por tarjeta, botones V / F, racha visible. Banco de
   plantillas con números al azar: a⁰ = 1 (V), a⁰ = 0 (F), a⁰ = a (F), 0ⁿ = 0 (V, n ≥ 1), 1ⁿ = 1
   (V), 1ⁿ = n (F), a¹ = a (V), a¹ = 1 (F), 10ⁿ = 1 seguido de n ceros (V), 10ⁿ = 10 · n (F), aⁿ =
   a · n (F), 2³ = 3² (F), 2⁴ = 4² (V, excepción famosa), aⁿ = a · a · … (V). Mitad y mitad.
   Feedback con la cuenta («1 · 1 · 1 · 1 · 1 = 1, no 5»). **0⁰ no aparece.**
2. **¿Cuál es la falsa?** Cuatro igualdades, tres verdaderas y una falsa, tocar la falsa
   (3C-30). Las cuatro de plantillas distintas para que sea de verdad una sola.

Ítem: `{ tipo: 'vf' | 'falsa', plantilla, a, n, verdad, opciones, solucion }`.
